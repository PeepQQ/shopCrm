# CRM для учета и реализации товаров

CRM-система для учета товаров, их количества и реализации в рамках бизнеса.

## Реализовано

### Панели

* Создание панели.
* Панель — изолированная сущность бизнеса: отдельная точка, место или магазин.

### Категории и товары

* Создание и редактирование категорий и групп.
* **Категория** — хранилище групп.
* **Группа** — хранилище товаров.
* Создание и редактирование товаров:

  * наименование;
  * цена.

### Реализация товаров

* Таблица товаров выбранной группы.
* Корзина и оформление продажи.

  * возможность указать скидку;
* История продаж

## В процессе / планы

* Страница оформления поставок товаров с изменением фактического количества.
* Страница списания товаров.
* Оптимизация лишних перерендеров и запросов к серверу.
* Реализация системы прав доступа к эндпоинтам с учетом ролей:

  * `Admin`;
  * `SuperAdmin`.
